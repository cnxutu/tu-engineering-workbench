# Spring Cloud 规则

## 服务调用

- 调用方必须配置连接与响应超时，并处理超时、限流、重试和降级的边界。
- 重试仅用于幂等操作；写操作须具备幂等键或去重机制。
- 不将下游错误直接透传给外部调用方，保留可追踪的错误码与关联标识。

## 配置与契约

- 配置应有默认值、环境说明和敏感信息隔离；禁止把密钥写入代码或日志。
- 服务发现、网关路由和消息主题变更应保持兼容窗口并具备回滚方案。
- 跨服务接口、事件和 DTO 的变更必须声明版本与兼容策略。

## 可观测性

- 关键链路传递关联 ID，并记录调用耗时、结果和必要业务标识。
- 为失败率、延迟、积压和关键业务结果设置可操作的监控指标。
