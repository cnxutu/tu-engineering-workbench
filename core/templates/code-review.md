# 代码评审任务

> **简写任务类型：`C`** — Code Review（代码评审）。
>
> 填写时可直接使用 `C` 与 `g/b/s/c/r/i/v` 简写；本页是防遗漏的完整参考。字段约定见 [Prompt Compact Syntax](../prompt-compact-syntax.md)。

## g — 目标（Goal）

<!-- 希望评审确认的质量目标或风险。 -->

## b — 背景（Background）

<!-- 需求链接、变更原因、相关设计和已有约定。 -->

## s — 当前状态（State）

<!-- 分支/提交范围、主要变更、已执行测试和已知问题。 -->

## c — 约束（Constraints）

<!-- 兼容性、安全、性能、发布窗口及明确不在本次范围内的事项。 -->

## r — 期望结果（Result）

<!-- 希望获得的评审结论、重点关注路径和输出格式。 -->

## i — 影响范围（Impact）

<!-- 受影响模块、接口、数据、用户、依赖和回归区域。 -->

## v — 验证方式（Verification）

<!-- 需检查的测试、场景、静态检查、日志或监控指标。 -->
