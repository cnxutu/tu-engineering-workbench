# 功能开发任务

> **简写任务类型：`F`** — Feature Development（开发）。
>
> 填写时可直接使用 `F` 与 `g/b/s/c/r/i/p/v` 简写；本页是防遗漏的完整参考。字段约定见 [Prompt Compact Syntax](../prompt-compact-syntax.md)。

## 使用示例

```text
范围：P0 + P1
F
g: 增加巡检任务状态查询接口
b: 页面需要展示运行中任务的状态
s: P1 已有任务状态缓存
c: 不修改 P2–P4；保持现有接口兼容
r: 提供按任务 ID 查询当前状态的接口
i: P1
p: 先定位缓存键和现有状态入口；复用已有缓存；完成后补充测试
v: 覆盖缓存命中、缓存未命中和任务不存在场景
```

<!-- 用户、场景、领域术语及相关链接。 -->

<!-- 已有能力、相关模块、接口或数据现状。 -->

<!-- 兼容性、性能、安全、时间、技术栈或不可修改范围。 -->

<!-- 行为、接口、数据、交互或交付物的具体要求。 -->
