# 跨服务变更任务

> **简写任务类型：`X`** — Cross-service Change（跨服务变更）。
>
> 填写时可直接使用 `X` 与 `g/b/s/c/r/i/p/v` 简写；本页是防遗漏的完整参考。字段约定见 [Prompt Compact Syntax](../prompt-compact-syntax.md)。

## 使用示例

```text
范围：P0–P4
X
g: 增加新设备的 OSD 上行和控制指令支持
b: 新设备需要复用现有 IoT 与 DJI 链路
s: P1–P4 已存在普通 OSD、DRC OSD 和下行命令通路
c: 不影响既有设备；普通 OSD 与 DRC OSD 保持独立语义
r: 明确各服务改动、契约兼容策略、发布顺序和联调项
i: P1、P2、P3、P4
p: 先读产品链路和各仓库入口；核实契约后按 P4→P3→P2→P1 评估实施与发布依赖
v: 分服务测试、端到端 MQTT 联调、兼容性回归和监控检查
```
