# Skill：问题排查

## 用途

用于定位异常、故障、性能退化或行为不符合预期的原因，并提出可验证的修复方案。

## 依赖

- Agent：[`Java Engineer`](../agents/java-engineer.md)；涉及数据时使用 [`Database Expert`](../agents/database-expert.md)
- Rules：[`Java`](../rules/java.md)、[`数据库`](../rules/database.md)
- Template：[`缺陷修复任务`](../templates/bugfix.md)
- Context：目标项目的日志、监控、部署版本、调用链和已知变更

## 流程

1. 收集可复现现象：时间范围、环境、请求/输入、期望与实际结果、频率和影响。
2. 沿调用链建立证据：日志、指标、配置、版本差异、数据状态和复现结果。
3. 将假设与证据分开，逐项排除，定位最小根因。
4. 提供修复方案，评估副作用、数据修复、回归范围和回滚方式。
5. 修复后用复现步骤和相关回归用例验证，并记录结果。

## 输出格式

按“现象、影响、证据、根因、修复方案、验证结果、风险与跟进项”输出。若尚未定位，输出下一步取证计划而非伪造结论。
