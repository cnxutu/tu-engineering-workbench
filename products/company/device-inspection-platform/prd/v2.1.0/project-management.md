# 项目管理

## 1. 需求概述

### 背景

平台需要把项目按项目集组织起来，并在项目集范围内维护成员、角色和空间资源。项目管理页面应提供项目集与项目的集中维护入口，避免前端分别操作 P1 关系表或 P7 通用标签接口。

### 目标

- 用户可以查看项目集和项目列表及基本信息。
- 用户可以创建、编辑项目集，并维护其成员角色和空间池。
- 用户可以在指定项目集下创建、编辑项目，并维护成员与空间绑定。
- 项目树、业务关系和项目权限边界保持一致，支持后续巡检业务按项目隔离。

### 非目标

- 不在本版本定义设备在线状态、巡检任务、媒体管理或部署拓扑。
- 不开放成员、角色、空间池和项目空间的独立 CRUD 页面。
- 不在本批次实现项目/项目集关闭和重新开启；项目/项目集移除按本 PRD 的软删除及关系解除规则执行。
- 不把项目业务关系写入 P7 `c_tag_relation`。

## 3. 用户与核心流程

### 3.1 项目集管理

1. 用户进入项目管理，查看项目集卡片或列表。
2. 用户点击创建项目集，填写项目集基本信息，并选择成员、成员角色和可用空间。
3. 系统校验编码、名称和关系集合，保存项目树节点及项目集关系。
4. 用户打开项目集详情，查看基本信息、成员及空间编码。
5. 用户编辑项目集时，提交完整的成员和空间编码集合，系统按目标集合完成新增、保留和移除同步。
6. 用户移除项目集时，系统校验全部直属项目没有执行中或暂停任务；校验通过后级联移除项目集、直属项目及其成员、空间关系。

### 3.2 项目管理

1. 用户从项目集进入项目列表，查看项目卡片和项目中心点。
2. 用户创建项目，选择所属项目集，填写项目基本信息和中心点，并选择成员与项目空间。
3. 系统只允许选择所属项目集空间池中的可用空间；已被同项目集其他项目绑定的空间不可选。
4. 用户打开项目编辑详情，查看所属项目集、成员选择状态、可用/已选/禁用空间状态。
5. 用户编辑项目时，提交成员和空间编码目标集合；所属项目集以既有项目关系为准，不因请求字段改变。
6. 用户移除项目时，系统校验项目空间下没有执行中或暂停任务；校验通过后解除成员、空间关系并标记项目为已移除。

### 3.3 保存失败与返回行为

- 保存前校验失败时保留用户已填写内容，不提交部分关系变更。
- 项目集或项目不存在时，详情、编辑和删除操作返回 not-found 结果，页面不得显示为成功。
- 关系冲突时，以服务端校验结果为准；典型冲突包括空间已被其他项目集/项目占用、项目集存在受保护关系时删除。
- 保存成功后的具体跳转位置、toast 文案和关闭弹窗行为属于原型视觉证据，当前标记为 `pending_verification`。

## 4. 产品需求

### 4.1 项目树

- 项目树固定为 `0003` 项目根 → 直属项目集 → 直属项目。
- 项目根只初始化，不允许业务编辑或删除。
- 项目集和项目通过 P1 项目管理门面维护，前端不直调 P7 通用标签接口。
- `config` 只承载扩展信息：项目集使用 `description`；项目使用 `longitude`、`latitude`。更新时保留未知扩展字段。

### 4.2 项目集信息与关系

- 项目集展示基本信息、成员及角色、空间编码。
- 项目集成员角色仅允许 `INS_PM_ADMIN`、`INS_PM_STAFF`；同一用户在同一项目集中只能拥有一个角色。
- 项目集空间池中，一个空间只能归属一个活动项目集。
- 项目集创建者自动成为项目管理员；管理员始终授权该项目集全部直属项目。创建者不得被移除或降级，当前登录项目管理员不得在保存中移除自身。
- 项目集移除前必须完成全部直属项目的运行任务校验；通过后级联解除成员、空间及项目集关系。

### 4.3 项目信息与关系

- 项目展示基本信息和中心点经纬度，用于地图标记。
- 项目必须归属一个项目集；创建时由 `projectSetCode` 指定，编辑时不得迁移项目集。
- 项目成员只维护项目与用户关系，角色继承所属项目集，不在项目成员关系中重复保存角色。
- 项目空间只能从所属项目集空间池选择；同项目集其他项目已绑定的空间进入禁用状态。
- 当前项目已经选择的空间不能被标记为禁用，以便用户取消选择。
- 项目移除前必须完成项目空间（含子空间设备）的运行任务校验；通过后解除成员、空间绑定。

### 4.3.1 项目（集）名称

- 项目集名称与项目名称各自在未移除范围内唯一；项目和项目集可以同名。
- 已移除项目或项目集可被同类型的新节点使用同名；P7 会保留被移除节点用于历史数据，但其 `tag_name` 不占用活动名称。
- P1 名称登记表的 `(node_type, normalized_name, is_deleted)` 唯一键是并发创建/改名的最终裁决；前端无需新增名称预检接口。

### 4.4 列表、详情与数据展示

- 项目集列表/详情返回项目集卡片、基本信息、成员关系和空间编码。
- 项目列表返回项目卡片及 `longitude`、`latitude`。
- 项目编辑详情返回所属项目集编码/名称、成员选择状态、`availableSpaceCodes`、`spaceCodes` 和 `disabledSpaceCodes`。
- 成员姓名、账号和部门由前端按 `userId` 调用 P6 补齐；项目管理响应不透传 P7 `TagDTO` 或 P1 持久化实体。

## 4.6 页面状态

以下状态是 PRD 的验收覆盖项；具体视觉样式和文案仍需原型复核：

- loading：列表、详情和空间树数据加载期间不得提交重复保存。
- empty：没有项目集、项目、成员或可用空间时，页面应能区分“暂无数据”和“当前无可选资源”。
- disabled：同项目集其他项目占用的空间不可选择；项目根不可编辑或删除。
- validation-error：必填、格式、重复关系和所属范围校验失败时，错误应定位到对应表单项或关系选择区域。
- conflict/not-found：空间占用冲突、受保护关系删除、节点不存在时，页面显示失败结果并保持当前上下文。
- success：保存或删除成功后刷新受影响列表/详情；跳转和提示文案待原型核验。

## 4.7 原型核验补充：项目管理首页与地图

- 页面分为项目集列表、项目列表和地图区域；项目集卡片展示项目集名称、项目数量、创建时间和描述，描述为空时展示“暂无描述”，超出两行省略并支持悬浮查看完整内容。
- 项目卡片展示项目名称、创建时间和描述；名称只展示一行，描述只展示两行；卡片提供“编辑”“移除”“进入”操作。
- 项目集列表为空时展示“暂无项目集”；项目集下无项目时展示“该项目集下暂无项目”，需要缺省样式。
- 地图仅展示项目中心点，不展示成果或其他标识元素；地图操作包括检索、测距、2D/3D、回中、放大、缩小和全屏。
- 点击项目集卡片：地图展示该项目集全部有效项目点位，以第一个有效项目为中心并使用固定默认缩放；无有效项目时使用地图默认中心和层级。
- 点击项目卡片：地图居中并高亮项目图标和名称；悬浮地图图标时，列表对应卡片同步选中，原选中项恢复默认状态。
- 地图区域受“地图显示/可操作宽度”约束，右侧列表区域不能被地图覆盖；不提供地图标识的新增或编辑入口。

## 4.8 原型核验补充：项目集表单

### 基本信息

- 项目集名称为单行文本，必填，最大 50 字符；不允许空格和特殊字符，仅允许中文、英文、数字、下划线、连字符。
- 项目集名称在失焦时校验非空、长度和格式，提交时再次校验未移除项目集内唯一性；已移除项目集可复用同名。空值提示为“请输入项目集名称”。
- 项目集描述为多行文本，原型标记为必填；最大 500 字符，输入时显示 `已输入 N/500`。未填写时系统填充“暂无描述”，列表卡片最多展示两行，超出省略并通过悬浮查看完整内容。
- 创建页标题为“项目集创建”或“新增项目集”；编辑复用创建表单并预填原数据。点击“返回”关闭页面且不保存。

### 成员配置

- 项目集成员通过“选择成员”弹窗维护；弹窗包含部门组织树和人员列表，顶部显示“已选中：N”，提供“确定”和“取消”。
- 部门树和人员列表只展示当前用户数据权限范围内的组织/人员；搜索不能突破数据权限范围。
- 已挂载到项目集的成员默认选中且复选框置灰，不能在选择成员弹窗取消；已存在成员通过行操作“配置”进入角色和授权项目配置。
- 项目角色为单选，原型展示“项目成员”“项目管理员”两个选项；新选成员默认“项目成员”。
- 授权项目为项目集下项目的多选集合。项目管理员默认全选且授权复选框全部置灰；创建者自动成为项目管理员、默认可访问全部项目，配置入口置灰；非创建者管理员不能配置自身，但可被其他管理员修改为项目成员并取消部分项目授权。
- 创建者和当前管理员自身不能点击“移除”；移除成员保存前需检查其是否仍在子项目驾驶舱拥有设备操控权限。

### 空间资源

- 项目集空间资源以树/节点复选框选择，勾选提交后生效；已被其他项目集关联的空间节点置灰，不能选择。
- 取消勾选空间时，提交前检查任一子项目在该空间下是否存在进行中任务；存在则阻断保存并提示“保存失败：以下空间存在进行中任务，请先处理后再移除。空间1、空间2、空间3”。
- 新增空间加入项目集资源池，并使该空间设备对所有子项目可见；移除空间解除项目集关联，自动从所有子项目移除项目空间关联，相关设备对所有子项目不可见。
- 已执行任务绑定的设备保留历史数据；未执行任务绑定的设备标记为“已移除”。
- 空间新增/移除后，正在查看设备列表或地图的用户需要手动刷新；对已被移除设备执行巡检监控、地图、驾驶舱操作时提示“该设备已被移除，无法操作！”，在航线/任务保存时提示“选择设备已被移除，无法保存！”。

### 统一保存

- 点击“完成”统一校验：项目集名称非空、格式合法且在未移除项目集内唯一；成员移除无进行中任务/设备操控权限依赖；空间移除无进行中任务依赖。
- 新建同时生成项目集记录并将创建者设为项目管理员；编辑同时保存基本信息、成员关系和空间关系，全部变更同时生效。
- 成功提示为“保存成功！”并关闭页面；失败提示需指出具体成员、空间、项目和进行中任务数量。

## 4.9 原型核验补充：关闭、重新开启与移除

### 关闭/重新开启

- 项目关闭前检查项目是否有进行中任务（原型列举普通任务、一键飞行任务/手动飞行任务）；有则阻断并提示先终止或完成任务。
- 项目关闭后显示“已关闭”状态：项目成员不能操控设备、进入驾驶舱、新建/执行任务或编辑配置；航线、任务、成果、AI 检测和 3D 模型等历史数据保留并只读查看。
- 项目集关闭前检查所有运行中子项目的进行中任务；关闭后项目集和运行中子项目进入只读状态，并自动级联关闭运行中子项目。
- 重新开启仅针对“已关闭”对象，确认弹窗标题为“确认开启”，确认按钮为“确认重新开启”（绿色）；开启后恢复操作能力。项目集重新开启自动级联开启已关闭子项目。
- 重新开启不恢复关闭前已移除的成员或空间资源；原型定义通过 WebSocket Toast 通知“项目「{项目名称}」已重新开启，可正常操作”。

### 移除/软删除

- 项目移除前检查进行中任务；确认弹窗标题为“确认移除项目”，正文说明业务数据将无法使用且项目成员、空间资源将被移出。
- 确认后项目标记为已移除（软删除），从项目列表隐藏，数据永久保留，解除所有成员和空间关联；操作者收到“项目已移除！”并更新项目卡片和项目数量。
- 被移除成员收到“您已被移出该项目。即将返回项目列表。”，原型定义 5 秒后自动跳转；项目集移除场景定义 3 秒后自动跳转。页面/卡片从列表消失。
- 项目集移除前检查所有子项目进行中或暂停任务；确认后项目集及其下项目标记为已移除，所有成员和空间资源移出，列表清空；项目集及直属项目的活动名称随之释放。
- 项目外访问被移除对象时提示“您已被移出项目，无法访问！”或“您已被移出项目集，无法访问！”，页面刷新后相关卡片消失。

## 4.10 原型核验补充：范围与权限

- 最外层项目集项目管理页展示项目管理入口，移除系统管理入口；项目详情页保留巡检监控、航线管理、任务管理、模型管理、电视墙、AI 检测事件、成果管理和历史轨迹等业务入口。
- 设备实时数据（IoT 数据、视频实时/录像数据）不受项目关联影响；航线、任务、成果、模型和告警业务数据与项目关联。
- 原型说明本版本告警不做数据权限隔离，全量展示；项目成员按个人操作进行账号级隔离。
- 关闭状态下，项目成员仅可查看历史数据；项目管理员还可查看项目配置（成员、空间、基本信息，只读），并具备重新开启/删除权限。该权限矩阵需与平台系统级权限共同核验。

### 5.1 约束矩阵

| 场景 | 必须满足 | 不允许 | 服务端结果 |
| --- | --- | --- | --- |
| 创建项目集 | 项目集基本信息合法、活动名称未被同类型有效节点占用，关系集合属于允许范围 | 重复名称、重复空间池归属、非法角色 | 拒绝保存并返回校验/冲突结果 |
| 编辑项目集 | 节点存在，目标关系集合可同步 | 修改项目根、创建者/当前管理员非法移除、存在驾驶舱或运行任务依赖时解除关系 | 拒绝不合法操作 |
| 创建项目 | `projectSetCode` 指向有效项目集，空间来自池内 | 无项目集创建、绑定池外或已占用空间 | 拒绝保存并返回校验/冲突结果 |
| 编辑项目 | 路径项目存在，所属项目集保持不变 | 借编辑请求迁移项目集 | 按既有项目集同步关系 |
| 移除项目 | 项目存在且空间下无执行中或暂停任务 | 绕过任务校验、产生部分关系删除 | 拒绝移除 |
| 移除项目集 | 项目集及其直属项目空间下无执行中或暂停任务 | 绕过子项目校验、产生部分移除 | 拒绝移除 |

## 6. 验收标准

- [ ] 可从项目管理入口查看项目集和项目，并能进入详情。
- [ ] 创建/编辑项目集可一次维护成员角色和空间池，关系集合与页面最终选择一致。
- [ ] 创建项目必须归属项目集，编辑项目不能改变所属项目集。
- [ ] 已被同项目集其他项目占用的空间不可选，当前项目已选空间可取消。
- [ ] 移除项目/项目集会完成任务阻断、关系级联解除、`REMOVED` 标记及受影响成员的权限失效通知。
- [ ] 同类型有效项目（集）同名被拒绝，项目与项目集同名允许；移除后同类型名称可复用。
- [ ] 项目列表可使用中心点渲染地图标记，项目详情返回项目集名称和空间选择状态。
- [ ] 项目管理页面不需要直接调用 P7 通用标签接口，不暴露持久化实体。
- [ ] 原型复核后，页面字段、必填状态、成功/失败提示和空态与本 PRD 逐项对齐。

### 6.1 详细验收场景

| 编号 | 场景 | 预期 |
| --- | --- | --- |
| PM-01 | 空数据进入项目管理 | 展示明确空态，并可进入创建项目集 |
| PM-02 | 创建项目集并配置成员角色 | 每个成员只有一个角色；创建者自动为项目管理员，关系可重复编辑 |
| PM-03 | 项目集空间池选择已属于其他项目集的空间 | 服务端拒绝，原有数据不被部分覆盖 |
| PM-04 | 项目集下创建项目并绑定空间 | 项目列表展示项目，中心点可用于地图标记 |
| PM-05 | 编辑项目尝试改变所属项目集 | 所属项目集保持不变，请求不产生迁移 |
| PM-06 | 同项目集两个项目竞争同一空间 | 后提交方收到冲突，已成功绑定方的数据不受影响 |
| PM-07 | 移除存在成员/空间的项目 | 无执行中或暂停任务时，成员和空间关系解除且项目隐藏；有运行任务则失败 |
| PM-08 | 移除包含项目的项目集 | 所有直属项目无运行任务时级联移除；任一项目有运行任务则整体失败 |
| PM-09 | 编辑项目取消当前已选空间 | 当前空间不因 `disabledSpaceCodes` 被锁死，可成功解除绑定 |
| PM-10 | 原型视觉复核 | 字段顺序、必填标识、按钮、空态、错误态和成功反馈逐项记录并回填本 PRD |
| PM-11 | 原型关闭项目 | 有进行中任务时阻断；关闭后业务操作冻结、历史数据只读 |
| PM-12 | 原型重新开启项目集 | 项目集和已关闭子项目级联恢复操作能力，不恢复已移除关系 |
| PM-13 | 原型移除项目集 | 软删除项目集及子项目，解除成员/空间关联，列表隐藏并向受影响用户反馈 |
| PM-14 | 项目集和项目名称校验 | 各自有效同名创建或改名被拒绝；二者同名允许；移除后同类型名称可复用 |
