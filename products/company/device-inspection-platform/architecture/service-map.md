# 服务地图

| 组件 | 已验证职责 | 非职责/未知 |
| --- | --- | --- |
| 巡检业务平台 | 巡检业务及媒体/视频能力 | 对外接口与状态机待验证 |
| IoT Server | IoT 服务能力 | 是否已集中作最终设备状态判定、完整生命周期接口均待验证 |
| IoT 网关 | 协议接入、连接、鉴权补齐、上下行转发 | 最终状态决策边界待验证 |
| DJI 适配器 | DJI 协议/SDK 映射 | 不作业务编排 |

相关流程见 [设备状态](../flows/device-online-flow.md) 与 [DJI](../flows/dji-protocol-flow.md)。
