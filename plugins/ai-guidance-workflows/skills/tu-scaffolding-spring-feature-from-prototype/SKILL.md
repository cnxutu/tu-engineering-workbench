# Legacy Prototype Compatibility

This Skill remains only for existing explicit invocations. Route the request to [tu-deliver-feature](../tu-deliver-feature/SKILL.md): create or resume one Delivery ID, begin with Impact, and use [tu-analyzing-feature-impact](../tu-analyzing-feature-impact/SKILL.md) for prototype evidence and backend disposition.

Do not reproduce the former fixed mega lifecycle, silently implement a Contract, or generate a Controller merely for Apifox. Preserve the caller's implementation authorization; the new Delivery workflow determines phase, Gate, authoritative artifact, and next action.
