# Skill：功能开发

## 用途

用于交付一个可验证的新功能，适用于有明确业务目标的接口、服务、页面或集成改动。

## 依赖

- Agent：`agents/java-engineer.md`；涉及设计时使用 `agents/backend-architect.md`
- Rules：`rules/java.md`、`rules/architecture.md`、`rules/database.md`、`rules/git.md`
- Template：`templates/feature.md`
- Context：目标项目的模块结构、业务术语、局部开发约定和测试方式

## 流程

1. 分析需求，确认目标、非目标、验收标准、约束和缺失信息。
2. 梳理影响范围：模块、接口、数据、权限、配置、兼容性、测试和部署。
3. 输出简要设计：职责划分、调用链、数据变化、异常语义和验证计划。
4. 在涉及接口、数据模型、跨模块协作或存在关键歧义时，等待设计确认。
5. 按现有模式进行最小实现，并补充相应自动化验证。
6. 执行可用验证，汇报实际结果、遗留风险和后续建议。

## 完成标准

功能满足已确认验收条件；影响范围已说明；验证已执行或明确说明未执行原因。不得把未确认假设实现为既定需求。
